# ПИТЕРСКИЙ СКАУТ — LIVE (тестовая сборка)

Откройте `index.html` для локального просмотра. Для установки в качестве PWA разверните содержимое папки на HTTPS-сайте и откройте `index.html`; на телефоне выберите «На экран Домой» или установку приложения в браузере.

## Что уже реализовано
- Пошаговая подготовка двух составов, номеров, амплуа и шестёрок 5–1 / 4–2 / 6–2.
- Выбор первой подачи, чередование в 2–4-й партиях, новая жеребьёвка для пятой.
- LIVE-ввод одним касанием для эйса, ошибки подачи или подачи в игре.
- Счёт, переход при Side-Out, сохранение шестёрки при успешной подаче, игрок зоны 1.
- Автоматический выход либеро вместо центрального при допустимой замене; раздельное назначение либеро для приёма и своей подачи, на площадке только один. Упрощённая модель: нестандартные варианты нужно подтверждать по правилам турнира.
- Обычные замены, защита от повторной незаконной пары и настройка лимита 6/8.
- Автоматическая последовательность «подача → приём → пас → атака» (всегда можно переопределить).
- Карты с координатами, тактическая схема, синхронизация с локальным видео, CSV/JSON не все виды экспорта (есть PNG/печать).
- Локальная история, экспорт JSON и отмена последнего розыгрыша.

## Известные ограничения
- Нельзя считать заменой официального электронного протокола FIVB; не покрыты исключительные замены, все санкции и нештатные судейские события.
- Полностью автоматическое распознавание видео, облачные аккаунты, синхронизация устройств, подписки, .dvw обмен и AI Coach **не реализованы**.
- Либеро и некоторые тактические схемы упрощены; сверяйте действия с реальным судейским решением.
- Данные в браузере: сохраняйте экспорт JSON после важных матчей. При первом чтении прежней локальной версии автоматически делается резервный снимок исходного ключа.
- Инструмент работает offline после успешной HTTPS-установки и загрузки shell, но это необходимо дополнительно проверить на целевых устройствах.
