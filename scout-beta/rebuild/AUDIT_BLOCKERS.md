# Независимый статический аудит LIVE rebuild — 2026-11-18
Статус: BLOCKED / не передавать тренеру как готовую версию.

Проверены исходники `scout-beta/rebuild/index.html`, `engine.js`, `engine.test.js` непосредственно в GitHub.
Ограничение: фактический браузерный E2E и запуск Node-тестов в этой проверке НЕ подтверждены; локальный runtime не смог скачать файлы из GitHub (DNS). Не путать статический аудит с успешным тестовым прогоном.

## Блокирующие дефекты
1. **LIVE ввод медленный.** Для обычного касания нужно выбрать игрока, тип, оценку и отдельно нажать «Добавить касание». Нет контекстного автошага, комбинаций клавиатуры и выбора зоны игрока без мыши.
2. **Редактирование завершённого розыгрыша неполное.** UI меняет только победителя через `prompt`, но не отдельное касание, оценку, игрока или зону. Движок допускает изменение массива `contacts`, но UI не использует эту возможность.
3. **Черновик теряется.** `draft=[]` хранится только в оперативной памяти и не записывается в `localStorage`; обновление страницы до окончания розыгрыша уничтожает касания.
4. **События касаний не валидируются.** `appendRally` принимает произвольный массив `contacts`; допускает подачу не тем игроком, касание игрока вне площадки, запрещённые действия либеро и несовместимый порядок действий.
5. **Нет полноценного регламента замен.** `applySub` не контролирует лимит замен и допустимые пары возврата стартового игрока; `applyLibero` не контролирует интервалы между заменами и нормативную последовательность.
6. **Состояние LIVE может стать противоречивым.** После записи черновика выбранный игрок может уйти с площадки вследствие перехода или замены; `pick` и `draft` не пересматриваются.
7. **Площадка и роли не готовы.** Жёстко заданные команды «Рубеж» и «Соперник», номера A1/B1, без полноценного редактора составов, связующих, амплуа и схем 5–1 / 4–2 / 6–2.
8. **Нет измерения скорости относительно Data Volley 4.** Не зафиксированы ни время, ни число действий для одинаковых розыгрышей.
9. **Нет подтверждённого E2E.** Отсутствуют результаты реального тестирования мышью, клавиатурой и сенсорным вводом в браузерах 390px/desktop.
10. **Потенциальная проблема интерфейса.** `render()` полностью перестраивает элементы выбора; это стирает текущие значения селекторов `out`/`incoming` и усложняет повторные действия. Выбранная оценка/зона также не получает заметной подсветки: CSS `.active` задан только для `.action`.
